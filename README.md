# 面包板连线项目

这个项目可以识别面包板俯视图中的孔，并允许用户通过鼠标绘制连接线。

## 功能特点

- 加载面包板图片
- 自动识别面包板上的孔
- 多种绘制工具：
  - **连线工具**：孔到孔的直线连接
  - **路径工具**：孔到孔的多点路径（左键添加转折点，右键完成）
  - **自由线条**：完全自由的线条绘制（左键添加点，右键完成）
  - **选择工具**：选中、编辑、删除线条，拖动自由线条的控制点
- 线条管理：
  - 选中线条查看和修改属性（颜色、线宽）
  - 删除单条线条（Delete键或按钮）
  - 撤销操作
  - 清除所有连线
- 保存/导出连线方案

## 使用方法

### 基本流程

1. 运行主程序：`python main.py`
2. 加载面包板图片
3. 点击"检测孔"识别面包板上的孔
4. 选择工具绘制连线：
   - **连线工具**：点击起点孔 → 点击终点孔
   - **路径工具**：点击起点孔 → 点击中间孔添加转折 → 右键点击终点孔完成
   - **自由线条**：点击起点 → 点击添加转折点 → 右键点击终点完成
5. 使用选择工具编辑线条
6. 保存结果或导出数据

### 工具对比

| 工具 | 起点 | 终点 | 中间点 | 可拖动 | 完成方式 | 用途 |
|------|------|------|--------|--------|----------|------|
| 连线工具 | 必须是孔 | 必须是孔 | 无 | ❌ | 点击终点 | 孔到孔的直线连接 |
| 路径工具 | 必须是孔 | 必须是孔 | 必须是孔 | ❌ | 右键点击终点孔 | 孔到孔的多点路径 |
| 自由线条 | 任意位置 | 任意位置 | 任意位置 | ✅ | 右键点击终点 | 完全自由的线条绘制 |

### 快捷键

- **右键**：完成路径/自由线条绘制
- **Delete**：删除选中的线条
- **空格 + 拖动**：平移画布
- **鼠标滚轮**：缩放画布
- **Shift + 拖动** 或 **中键拖动**：平移画布
